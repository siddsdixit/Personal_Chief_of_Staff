---
description: "Summarize a Slack thread"
---

$ARGUMENTS should include a channel name or thread link.

Read the thread via your Slack MCP tool. Summarize:

```
**Thread summary: [channel/topic]**

**Who's involved:** [names]
**Key points:**
- [point]
- [point]

**Open question / decision needed:** [if any]
**Last activity:** [when, by whom]
```

If the user was asked something in the thread and hasn't replied, flag it explicitly and
offer to draft a reply.
